## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 서버나 외부 라이브러리가 필요하지 않습니다.

- PC: 방향키 / WASD / 스페이스 등 게임별 조작
- 모바일: 화면 하단 터치 조작 버튼 지원
- 최고 기록: 브라우저 `localStorage`에 저장
- Rolling Sky 500: 스테이지 선택기에서 1~500을 선택 가능하며, 스테이지 번호를 시드로 사용해 패턴과 난이도를 생성합니다.
